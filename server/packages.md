# packages used.

+ Express : fast and minimal
+ cors : handle cors securities.
+ dotenv : access env 
+ helmet : security headers
+ morgan : logging all the requests.
+ sequelize : object relational mapping
+ pg pg-hstore : sequelize postgress support
+ sequelize-cli : migrations management (development)
+ jsonwebtoken : JWT management
+ bcryptjs : User High valued data hashing
+ joi : request parametars and body validation.
+ uuid : To manage long unpredictable ids.
+ nodemon : auto restart server when change (development)
