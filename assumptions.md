# Assumptions and further enhancements


## Assumptions

+ Partial feedback: Assuming this as employee is not limited for only one feedback, he can give one and more feedbacks (and limited upto 5).
+ Feedback Cycle : Assuming that by keeping feedback cycle, admin can create new instance of reviews for next work cycle feedback.

## Further enhancements

+ **Performance Factors**: Gives more accuracy while giving feedback.
+ **User Search**: If it more users, keeping user search while assigning users gives good user experience.
+ **Department management**: Instead of managing, giving one more option as department or teams can admin also assign directly to all.
+ **frontend validation**: Corrently all basic validation in frontend is handlied, Advance validation can be done (showcasing error for every fields) for better ux.
+ **communication**: Notifying users through mail or any other medium, so that employees comes to know when they receive review requirement.
+ **Technical**: Secure Origin, Unit and Integral Test Cases, Advance ratelimiting, Audit logs.
